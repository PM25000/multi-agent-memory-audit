# Evidence map and data dictionary

- An input-record group pairs a complete synthetic input with one candidate memory
  record. S8/evidence/frame.json defines 1644 groups in three task-count strata;
  sample.json identifies 96 sampled groups and their inclusion probabilities.
- S8/evidence/cases.json gives requests, memories, candidate records and tasks.
  judgments_A/B.json are original independent judgment-field projections;
  judgments_C.json is adjudication after seeing A/B alternatives. resolved.json
  keeps the origin of each final decision. No original answer-export files are
  included. Reviewer codes are not real identities.
- S2/groups.json and sensitivity/contributions.json supply transmission-weighted
  semantic contributions. Both necessity endpoints are retained. Design-based
  uncertainty is conditional on valid labels; A/B envelopes are sensitivity
  analyses, not additional confidence intervals.
- S3 contains saved literal selector responses and parsing attempts. S8 selections
  derive retained grade-3 selections; S3-selection-link-map.json links 450 source
  records to their original byte identities. Synthetic contact/identifier strings
  are retained because literal-value matching is part of the evaluation.
- S5 separates initial model labels, partial A/B checks and author decisions.
  W03 is ranking sensitivity only, outside the 11-workflow primary total.
- S6/S7 retain requests, actual provider receipts, native messages, tool actions,
  pre/post worlds and finite scores. Program contracts are not human necessity or
  authorization gold. Aliases/named positions are not independent executions.
- Failed outputs, incomplete transport, format failures and negative findings in
  the included final studies remain observable. Aborted predecessor campaigns
  are excluded from the public outcome data, not relabeled as successful trials.

The source SHA-256 values and PUBLIC_MANIFEST.json identify bytes, not semantic
truth, consent records or historical wall-clock authenticity.
